### PID Optimization Workflow for Wave Energy Converter

1. **Open the Project Folder**
   Navigate to the folder named `DL_Project_Resources`.

2. **Launch MATLAB and Open Simulink Model**
   Open MATLAB, then open the Simulink model file named `DL_project.slx` located inside the `DL_Project_Resources` folder.

3. **Run Data Collection Script in MATLAB**
   In the MATLAB Command Window, run the script named `data_collector`. This script performs the following:

   * Simulates 250 different PID parameter combinations (`Kp`, `Ki`, `Kd`) in the Simulink model.
   * Records the corresponding power outputs for each combination.
   * Automatically generates and saves an Excel sheet containing this data in the current MATLAB folder.

4. **Run Machine Learning Model for PID Optimization**
   In the same folder, open the file `PID_optimizer.ipynb` using Jupyter Notebook. This notebook will:

   * Load the Excel file generated by the MATLAB script.
   * Use the data to train or apply a machine learning model.
   * Generate 500,000 different PID parameter sets.
   * Predict the power output for each set.
   * Identify and output the optimal PID parameters that yield the maximum power.

This completes the process of data generation and ML-based PID parameter optimization for efficient energy extraction in a simulated Wave Energy Converter system.
